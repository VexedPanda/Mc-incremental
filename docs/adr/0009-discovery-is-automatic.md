# Discovery is automatic: anything produced or held enters Knowledge

ProjectE only learns an item when a player puts it into a transmutation table. We decided that a resource enters the world's Knowledge as soon as anything in the world produces it or a player holds it, because a forgotten manual step would cost a whole Run's discoveries at Prestige, and because resources that are only ever made (fusion products, synthetic chemicals) then need no special mechanism. Dimension gates still limit where resources can be found, so automatic discovery never lets players skip progression.
